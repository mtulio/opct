# Assisted Review Conformance Results

This development guide helps you to understand how to review the conformance workflows generated by OPCT.

The public of this document is everyone who have access to a Claude environment. (?)

## Prerequisites

- Claude CLI


```sh
export OPCT_PROMPTS=/home/mtulio/go/src/github.com/mtulio/opct/docs/devel/assisted-review

```

## Usage


```sh
claude "Please provide the summary of the workflow, and action items of failures." \
--allowedTools "Bash(curl:*) Read" \
--append-system-prompt "${OPCT_PROMPTS}/system.prompt.txt" \
--settings "${OPCT_PROMPTS}/settings.local.json" \
--add-dir "${OPCT_REPORT_DIR}" \
--add-dir "${OPCT_PROMPTS}" \
--strict-mcp-config \
--mcp-config 
--mcp-debug



--mcp-config
--model


```
